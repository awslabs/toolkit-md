# Workshop Overview

This workshop teaches you how to operate containerized workloads on a
managed Kubernetes cluster. You will deploy a sample retail application,
configure observability, and practice common operational tasks.

The workshop takes approximately two hours to complete. Each module
builds on the previous one, so complete them in order.

## What you will learn

- How to deploy applications using declarative manifests
- How to inspect workloads and diagnose common failures
- How to configure horizontal scaling based on observed load
