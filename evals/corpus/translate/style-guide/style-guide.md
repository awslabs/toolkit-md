# French Translation Style Guide

Follow these conventions when translating workshop content into French.

## Terminology

Use these French terms consistently. Do not keep the English term even
though it is common in French technical writing.

| English | French |
| ------- | ------ |
| cluster | grappe |
| worker node | nœud de travail |
| deployment (the Kubernetes resource) | déploiement |

## Voice

- Use the formal "vous" form when addressing the reader.
- Keep sentences short and direct.
